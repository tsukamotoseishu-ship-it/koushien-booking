# 印刷リレー（フロントPC用）

TSP100III(TSP143IIILAN) はCloudPRNT非対応のため、予約サーバー(Render)から直接プリンターへは印刷できません。
代わりに、このPC上で動くこの小さなプログラムが「予約サーバーに新しい予約がないか問い合わせ→あればWindowsプリンターに印刷」を繰り返します。

## 事前準備

1. **Node.js** がこのPCに入っていること（なければ https://nodejs.org からLTS版をインストール）
2. **futurePRNT** ドライバをインストールし、プリンターを通常のWindowsプリンターとして登録しておく（設定→デバイスとプリンター で確認）
3. 登録されているプリンターの**正確な名前**を控えておく

## 設定

1. `start.ps1` をメモ帳などで開く
2. 以下の3行を書き換える：
   - `PRINT_RELAY_TOKEN` → 塚本さんに別途(LINEやメールなど)問い合わせて教えてもらう値
   - `PRINTER_NAME` → Windowsに登録されているプリンターの正確な名前
   - `API_BASE` はそのままでOK
3. 保存

同じトークンを、Renderの `koushien-booking` サービスの環境変数 `PRINT_RELAY_TOKEN` にも設定する必要があります（Renderダッシュボード → koushien-booking → Environment → Add Environment Variable）。すでに設定済みであれば不要です。これは塚本さんが対応します。

## 実行

`start.ps1` を右クリック →「PowerShellで実行」。ウィンドウが開いたままになり、ログが流れ続けます。これが動いている間だけ印刷されます。

テスト予約を1件入れて、5〜10秒以内にこのウィンドウに `printing job #1...` のようなログが出て、プリンターから紙が出てくれば成功です。

## 自動起動させる（PCを再起動しても動き続けるように）

1. `Win + R` → `shell:startup` と入力してEnter（スタートアップフォルダが開く）
2. `start.ps1` のショートカットをそのフォルダに作成する

これで次回PC起動時から自動的に印刷リレーが立ち上がります。
